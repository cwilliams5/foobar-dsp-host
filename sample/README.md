# sample/

`demo.wav` is an **original synthesized clip** — a short chord progression with bass, an arpeggio, and
hi-hat-like transients — created for this repository and dedicated to the public domain under
**CC0 1.0**. Use it for anything; no attribution required.

It's deliberately broadband and rhythmic so DSP effects (EQ, level, loudness, exciter) are clearly
audible when you A/B in the lab. To use a different track, drop your own `test.mp3` / `test.flac` /
`test.wav` in the repo root — the lab prefers that if present.
